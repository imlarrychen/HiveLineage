# Bug 修复记录

本目录用于保存可审计、可复现的 Bug 修复记录。每次修复 Bug 时必须：

1. 复制下方模板新建 `YYYY-MM-DD-简短问题名.md`，或在同一问题的既有记录中追加新的复现形式。
2. 先新增能够复现问题的自动化测试并确认失败，再修改生产代码使其通过。
3. 运行相关测试与完整测试，将实际结果写入记录。
4. 修复记录和回归测试与生产代码在同一修复分支提交并一同评审。
